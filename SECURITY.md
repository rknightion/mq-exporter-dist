# Security

Report suspected vulnerabilities privately using this repository's
[security advisory form](https://github.com/rknightion/mq-exporter-dist/security/advisories/new).
Do not include credentials, private infrastructure identifiers or diagnostic dumps
in public issues. Use synthetic examples and a minimal reproduction.

This community project has no guaranteed response time or support SLA. Candidate
releases have provisional platform support; see the compatibility matrix before
deployment. For vulnerabilities in IBM MQ or the upstream collector, use the
respective vendor or upstream reporting process.
